# Kuala Lumpur — Cinema travel story

Mockup statico HTML e CSS per una travel story cinematografica: tre fotografie di Kuala Lumpur in pieno formato, con testo e osservazioni sovrapposti da un gradiente scuro continuo.

Per aprirlo localmente dalla cartella del progetto:

```sh
python3 -m http.server 8000
```

Poi visita [http://localhost:8000](http://localhost:8000).

Editing, export, persistenza e pubblicazione sono fuori scope: questa è una composizione statica Cinema-only.
